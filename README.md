## Password Strength Checker Web App

This is a simple **Password Strength Checker** built using **HTML, CSS, and JavaScript**.  
It visually evaluates the strength of a password based on multiple conditions like length, uppercase letters, numbers, and special characters.

---

##  Features

- Real-time password strength detection  
- Strength indication using color-coded progress bar  
- Simple and clean UI  
- No backend required (pure frontend project)

---

##  Technologies Used

 Technology  Purpose 

## HTML      :- Structure of the webpage 
## CSS       :- Styling and layout 
## JavaScript:- Password logic and strength evaluation

## How It Works

The password is evaluated based on:

Minimum length (≥ 6 characters)

Contains uppercase letters

Contains digits (0-9)

Contains special characters (!,@,#,$,% etc.)

Depending on how many rules are met, the strength bar increases from:
Weak → Medium → Good → Strong
